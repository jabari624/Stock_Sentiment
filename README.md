# Stock_Sentiment
Impact of Social Media Sentiment on Short Term Stock Price Performance
ECON 3321/5321 Final Project Instructions
Overview
For the final project, you will demonstrate the skills you have learned in the course by performing a complete data analysis. This is not only a way to build your skills and evaluate what you learned in this course — a well-executed project will be an invaluable addition to your portfolio when it comes time to apply for jobs or further education.

Much like the problem sets, you will create a markdown document that includes both your code and analysis. However, the final project will additionally require you to develop research questions and interpret your results. It should not consist of only code and output, but should include sections of text describing and interpreting your analysis. It will also be much more open-ended than your problem sets; At each step, you will need to decide what to do, how to do it, and how to interpret the result. You will present your project in class, receive feedback, and then submit a final version with revisions.

DO NOT LEAVE THIS PROJECT UNTIL THE LAST WEEK. You will need time to think about your data, to clean it, to process it, and to analyze it. Since you have multiple weeks to complete this, the amount of work should be comparable to multiple problem sets.

Data
You should obtain at least two distinct data sets that you can join together to explore your research question(s). These should not be standard data sets that are used for teaching, and they should be large enough to be interesting. You will receive credit for any cleaning that is required, so you are encouraged to use data that is a little bit messy. It should be possible to use a join operation to combine the data into a single data frame (possibly after some cleaning/aggregation/processing). You should not use strictly time-series data, as this requires techniques we have not covered in class. Instead, look for cross-sectional data or panel data with multiple variables.

Research Question(s)
You should develop one primary research question that you can answer with the data you have chosen. As you dig into the data, you may modify this question or develop additional questions. These do not need to be complex or particularly novel, and you are not expected to do any formal causal inference, as we have not covered that in this course. Instead, you will likely be looking at correlations, and exploring (conditional) relationships between variables of interest, which is a common approach in the preliminary stages of research. Unlike a true research project, the emphasis here is more on the journey than on the final conclusion. I am happy to provide feedback regarding your data and research question — just send me an email.

Analysis
Your analysis should include at least the following components, roughly in the order listed:

Raw data description
where it is from (including a hyperlink to the source)
how the data was gathered/compiled (e.g., administrative data from a government)
what it contains (columns, data types, etc.)
some context
Data cleaning
properly format column names
set data types
document and deal with missing values
check for potentially incorrect data, etc.
Data processing
join secondary data
calculate and/or aggregate to obtain new variables for your analysis
Processed data description
check the quality/correctness of the join
summary statistics tables
summary and analysis plots (publication quality)
Statistical analysis
regressions with summary tables
Discussion
interpretation of results
limitations of your analysis
Report
Like the problem sets, your final project report should be generated using a markdown document that includes all of your code and analysis. It should include the components listed and described above. At each step, you should include concise explanations justifying, describing, and interpreting your analysis. Your report should be well-organized and easy to follow. To this end, you should include a title, your name, section headings and subheadings, and a table of contents. The report should include a brief introduction, along with a section for each component of the analysis listed above. Tables and plots should be tidily formatted and appropriately labelled (i.e., publication quality).
